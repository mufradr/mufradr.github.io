# Historical baseline detail

These are simulated outcomes, not desired historical dates. Default Earth seeds are independent samples; the generated world is a separate experiment. Dates below follow the app’s BCE/CE display. State identity changes can look like abrupt imperial falls. The small initial sample cannot establish regional success rates.
